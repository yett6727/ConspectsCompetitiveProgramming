### СНМ и асимптотические оптимизации
Идея СНМа ясна и стара как мир - необходимо реализовать функции get(v), возвращающую родителя корня и функцию union(x,y), объединяющую множества с вершинами x и y
Будем хранить вектор parent[x] - родителя x по индексу и -1, если x - родитель
```cpp
int dsu_get(int x){
	if (parent[x] == -1) return x;
	return dsu_get(parent[x]);
}
```
Теперь мы умеем проверять, лежат ли x и y в одном мнодестве.

Теперь объединим множества, переподвешивая родителя одного множества к родителю другого
```cpp
void dsu_union(int x, int y){
	parent[dsu_get(x)] = dsu_get(y);
}
```

Напишем полный псевдокод:
```cpp
vector<int>parents;

	if (parent[x] == -1) return x;
	return dsu_get(parent[x]);

	return false;
}
```
Оценим асимптотику и заметим, что в принципе может довольно долго работать наш СНМ, а именно подъем может совершатся аж за O(n), так как можем получить множества, вырождающиеся в бамбуки

Так что воспользуемся асимптотиками: размерной и ранговой - они равны асимптотически, но имеют разную идею

#### Первая эвристика
Первая эвристика- будем подвешивать вершину к корню напрямую, таким образом наше дерево будет иметь глубину 1 и мы будем подниматься за 1
Воспользуемся таким методом:
```cpp
int dsu_get(int x){
	if (parent[x] == -1) return x;
	return parent[x] = dsu_get(parent[x]); //!
}
```
Теперь когда мы обратимся к dsu_get(x), то все вершины на пути от x до корня переподвесятся к корню
Теперь подъем работает не за $O(n)$, а за $O(log(n))$, что является хорошей оптимизацией

Большая проблема такой эвристики, что в некоторых задачах необходимо знать настоящего, первого родителя вершины

#### Вторая эвристика
Воспользуемся размерной эвристикой
Для дерева на k вершин, его глубина не больше $\lfloor log_2(k) \rfloor$.

### Алгоритм Краскала
Причина обсуждения СНМ - использование СНМ для Краскала
Напишем СНМ, которым будем пользоватся в задаче:
```cpp
vector<int>parent;
vector<int>dsu_size;

int dsu_get(int x){
	if (parent[x] == -1) return x;
	return parent[x] = dsu_get(parent[x]);
}

void dsu_union(int x, int y){
	x = dsu_get(x);
	y = dsu_get(y);
	
	if (x == y) return;
	if (dsu_size[y] > dsu_size[x]) swap(x,y);
	
	parent[y] = x;
	dsu_size[x] += dsu_size[y];
}

int main(){
	int n; cin >> n;
	
	parent.assign(n,-1);
	dsu_size.assign(n,1);
}
```

Реализуем алгоритм Краскала:
```cpp
vector<pair<int,pair<int,int>>>edges(m);
for (auto& edge : edges)
	cin >> edge.second.first >> edge.second.second >> edge.first;

sort(edges.begin(), edges.end());

int ans = 0;
for (int i = 0; i < m; i++){
	int u = dsu_get(edges[i].second.first);
	int v = dsu_get(edges[i].second.second);
	
	if (u != v){
		dsu_union(u,v);
		ans += edges[i].first;
	}
}

cout << ans; //вернет сумму весов в остовном дереве с максимальным суммарным весом ребер
```
Получаем жадный алгоритм Краскала, реализованный через СНМ
Итоговая асимптотика $O(E \log E + E \log V)$, на практике вырождается в $O(E\log V)$.
