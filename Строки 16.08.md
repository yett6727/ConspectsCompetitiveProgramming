## Хэширование
К сожалению сравнение строк работает за линию, а при больших строчках это может быть долго, так что попробуем научится быстро сравнивать строки
Для этого каждой строке сопоставим число, которое с хорошей точностью будет уникальным для разных строчек
Это будет называться хэшом строчки, и хэшом префикса строчки $s$ длины $i$ на алфавите размера $m < p$ будет называться число $$h[s] = (p^{i-1}s[i] + p^{i-2}s[i-1]+\dots+s[0])\operatorname{mod}M$$
Тогда попробуем научится получать хэш подотрезка(полуинтервала) $[l;r)$.
$$h[l;r) = h[r] - p^{r-l}h[l]$$
Теперь любой строке и ее подстроке сопоставлено число, благодаря $p>m$ с хорошей точностью уникальное. В прицнипе пока наши хэши не вылезают за $10^9$(или размер нашей численной переменной), мы можем их спокойно сравнивать.
	Какие модули брать под хэши?
Под хэши хорошо подойдут $10^9+7$, $10^9+9$, $10^9+1000-7$, $10^9+179$.
Лучше всего выбрать любимый модуль для хэшэй, однако иногда хэши могут взрываться из-за парадокса дней рождений.
#### Парадокс дней рождений
Какое минимальное количество учеников в классе должно быть, чтобы с вероятностью хотя бы $\frac{1}{2}$ было два человека, у которых день рождения будет в один день. Согласно теории вероятностей, ответ равен $23$.
#### Хэши на переполнениях
Существует техника хешей на переполнении, где используется модуль $2^{64}$(размер unsigned long long в C++), и его переполнение происходит без UB, поэтому можно бесплатно работать по модулю. Однако слово Туэ-Морса ломает такие хеши, так что лучше так не делать, так как на cf например почти всегда тест с Туэ-Морса лежит.
#### Реализация
$h[i]=((ll)p * (x[i-1]\operatorname{mod}M)+s[i-1])\operatorname{mod}M$

int add (x,y){ //вводим функцию сложения, так как операция модуля довольно дорогая
	if (x + y >= M) return x+y-M;

int sub(x,y){
	if (x - y < 0)return x-y+M;

int mul(x,y){ //c умножением хитрости не пройдут, придется честно кастить к лонгам и считать

#### Проверим строки на равенство
Допустим есть строки $s$ и $t$. Тогда сделаем бинпоиск по длине префикса, если $h_s[x]=h_t[x]$, то двигаем левую границу, иначе правую. Отсюда следует важная идея бинпоиска по ответу с хешами. По итогу бинпоиска мы сможем найти первый момент расхождения строк(или факт того, что они равны)
#### Палиндромы
Палиндромы делятся на $2$ глобальных случая: строки четной и нечетной длины
1. Строки четной длины: можно выкинуть центральный элемент, реверснуть одну из строк и сравнить их
2. Строки нечетной длины: можно разбить пополам и также сравнить
## Бор
Ну что такое бор я уже знаю: переход по ребру в вершину $c$ равносилен добавлению $c$ в конец строки. Вершины, в которых закончилась строка из обхода, являются терминальными.
Добавление строки $s$ длины $n$ в бор происходит за $O(n)$.
Хотим научится находить количество строчек в боре, имеющих префикс $p$.
#### Добавление
Идем по строке и по бору. Если есть уже переход с такой строчкой, мы просто пройдем по ребру, если нет, добавим ребро. По необходимости добавим терминальную вершину
#### Ответ на запрос
Работает за $O(m\cdot \sum |s|)$, где $m$ - размер алфавита. В прицнипе цифры приличные
#### Удаление
Научимся отвечать на запрос удаления строки из бора. Удалять руками довольно сложно, так что просто опустимся в слово, сделаем его терминальную вершину нетерминальной и затем просто поднимемся наверх и пересчитаем $dp$.
#### Реализация
```cpp
struct Node {
	vector<int>t(26,-1);
	bool term = false;
}

struct Trie {
	vector<Node>tr;
	
	Trie(){
		tr.push_back(Node());
	}
}

void add(string s){
	int cur = 0;
	for (int i = 0; i < n; i++){
		int c = s[i] - 'a';
		if (tr[cur].t[c] != -1){
			cur = tr[cur].t[c];
		} else {
			tr.push_back(Node()){
				tr[cur].t[c] = tr.size() - 1;
			}
		}
	}
	
	tr[cur].term = true;
}
```
